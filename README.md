# BasketBuddy 🛒

BasketBuddy is a full-stack grocery search and basket-building web app that lets users search products, manage a persistent basket, and redirect to retailer checkout.

🔗 **Live Demo:** https://basket-bud.vercel.app

---

## Features

- 🔍 Search grocery products
- 🛒 Persistent basket tied to user accounts
- ➕ Increment / decrement item quantities
- 🗑️ Automatic removal when quantity reaches zero
- 🔐 User authentication
- 🏪 Redirect to retailer product pages (Kroger)
- ☁️ Fully deployed frontend and backend

---

## Tech Stack

### Frontend
- Next.js (App Router)
- TypeScript
- Supabase Auth
- Vercel

### Backend
- Node.js
- Express
- Supabase (Service Role for secure access)
- Kroger API
- Render
